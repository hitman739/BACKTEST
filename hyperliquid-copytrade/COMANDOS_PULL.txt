CÓMO INICIAR EL SIMULATOR
===============================================

Opción 1 - Manual (recomendado para ver logs):

   cd ~/Documents/BACKTEST/hyperliquid-copytrade/backend
   python3 api_simulator.py

Opción 2 - Con script:

   cd ~/Documents/BACKTEST/hyperliquid-copytrade
   ./scripts/start_simulator.sh

===============================================
CÓMO INICIAR ULTRA COPY TRADING
===============================================

   cd ~/Documents/BACKTEST/hyperliquid-copytrade/backend
   python3 api_new.py

===============================================
CÓMO INICIAR EL FRONTEND
===============================================

   cd ~/Documents/BACKTEST/hyperliquid-copytrade/frontend
   npm install  # Solo la primera vez
   npm run dev

===============================================
ENDPOINTS DISPONIBLES
===============================================

Simulator (puerto 8000):
- POST /sim/start
- GET /sim/snapshot?wallet=...
- GET /sim/debug/{wallet}
- GET /docs

Ultra Copy Trading (puerto 8000):
- POST /wallet/add
- GET /status
- WebSocket: ws://localhost:8000/ws

Frontend (puerto 5173):
- http://localhost:5173/
